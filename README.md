# **Quiz App Backend**

## Overview

A real-time quiz application backend built with TypeScript and Express.js, featuring RESTful APIs and Socket.IO for real-time gameplay.

## About my app

- Tech stack: TypeScript, Express.js, PostgreSQL, Socket.IO
- Features: User authentication, quiz management, real-time game sessions, AWS S3 integration

## Quick Start

- Requirement: Docker
- Config .env file or copy .env.example to .env
- Run follow this command

```cmd
docker compose up
```
